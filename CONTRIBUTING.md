# Contributing

Thanks for taking a look.

This repository currently contains early design notes shared for feedback.
I’m building this primarily for personal use and validating assumptions before
writing significant code.

## What’s welcome
- Design critique
- Suggestions about edge cases or failure modes
- Pointers to existing tools or prior art

## What to expect
- Issues and discussions are preferred over pull requests
- Pull requests may be slow to review or declined
- There is no roadmap or release schedule

## Out of scope
- Hosted services or SaaS features
- User accounts or telemetry
- Monetization proposals

Thanks for understanding.
