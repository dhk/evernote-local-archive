# Scope and Non-Goals

This document exists to clarify intent and avoid confusion.

## In Scope
- Local-only workflows
- Filesystem-based storage
- Open, inspectable formats
- Optional local indexing
- Manual or semi-automated processes

## Explicitly Out of Scope
- Hosted services
- User accounts
- Telemetry or analytics
- Mobile apps
- Real-time sync
- Enterprise or multi-user features
- Monetization of any kind

If a proposal requires servers, credentials, or background services, it is out of scope.
